# Downloads

A versão mais recente do Desktop-Pet fica na página de versões do GitHub: <https://github.com/lfeliipeadv-stack/Desktop-Pet/releases/latest>. A página do projeto, <https://lfeliipeadv-stack.github.io/Desktop-Pet/>, tem o botão de download e a demo no navegador.

| Arquivo | Para quem |
| --- | --- |
| [DesktopPet-Instalador.exe](https://github.com/lfeliipeadv-stack/Desktop-Pet/releases/latest/download/DesktopPet-Instalador.exe) | **Recomendado.** Confere o .NET 10, instala o programa e o Editor de Pets e cria os atalhos. |
| [DesktopPet-completo.exe](https://github.com/lfeliipeadv-stack/Desktop-Pet/releases/latest/download/DesktopPet-completo.exe) | Abre direto, sem instalar nada (arquivo maior, com o .NET dentro). |
| [DesktopPet.exe](https://github.com/lfeliipeadv-stack/Desktop-Pet/releases/latest/download/DesktopPet.exe) | Só o programa, para quem já tem o [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). |
| [PetEditor.exe](https://github.com/lfeliipeadv-stack/Desktop-Pet/releases/latest/download/PetEditor.exe) | O Editor de Pets, para criar e mudar pets. O instalador já traz, e o programa baixa sozinho na primeira vez que você abre Configurações › Editor de Pets. |

Os arquivos não têm assinatura digital, então o Windows pode avisar que o editor é desconhecido. Cada versão publica o `SHA256SUMS` para conferir o download: veja [Instalação](https://lfeliipeadv-stack.github.io/Desktop-Pet/wiki/Instalacao.html).

O que mudou em cada versão está no [Changelog](Changelog.md).
