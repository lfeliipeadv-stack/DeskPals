# Tico

## Descrição

Um menininho em pixel art, de macacão azul com capuz de orelhinhas de urso.

Ele anda balançando pela tela, corre de braços para cima, anda na ponta dos pés, marcha e senta
balançando os pés. Uma bola rola até o pé dele e ele chuta longe, o balão vermelho escapa, ele faz
bolhas de sabão, segue uma borboleta, pula numa poça, pega uma estrela cadente e ri quando um
passarinho pousa no capuz.
