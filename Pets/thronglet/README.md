# Thronglet

## Description

A little yellow pixel creature with an antenna. It hatches from an egg, walks, naps,
plays with a sword, a map and a lantern, sneezes, laughs, gets dizzy, dodges a falling
boulder and, now and then, turns on a jukebox and dances a whole song.

Fan art inspired by the Thronglets of *Black Mirror* ("Plaything"). Not affiliated with
Netflix or the series. The jukebox song is an original chiptune tune made for this pet.

## About pet

Author: Luan Felipe

## Animations

* hatch from an egg, walk, turn, fall, climb onto windows
* sleep, sit, blink, wave, laugh, sneeze, get dizzy
* sword, shield, map, lantern, rope, pickaxe
* the jukebox show: it appears, lights up, plays and the Thronglet dances
